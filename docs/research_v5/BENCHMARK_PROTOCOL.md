# Pre-implementation study protocol

E0: unchanged V4 contextual prompt and Gemma schema-in-packet contract, replay
existing 32+16 answers. E1: saved primary A2 failure only, clearly different model.
E2: authored atomic semantic oracle, no network. E3: one semantic call to
`gemma4:31b`, then code-generated addresses, relation IDs and witness paths.
E4 is optional only if an observed, correctly interpreted norm has unresolved
role grounding. No E4 by default.

Wire: bounded nonrecursive disjunctions of conjunctions, atom negation, rule-local
exceptions, modality and applicability. Business participants are free text from
input; operands and joins select only code-generated scalar-field candidates.
Out-of-language grouping remains an explicit gap. Code membership/arity and
native relation truth do not certify normative meaning. Empty rules require an
explicit coverage opinion and cannot bypass an unresolved effect.

First online phase: eight smoke cases spanning prior authorization, entity swap,
future approval, immutable observation, opaque effect, AND/OR, scoped exception
and false-success prose. Hard ceiling 40 HTTP attempts / 100,000 charged tokens,
one attempt per wire request, 120-second timeout, no 429 retry. Preserve raw
before parse. Expansion uses a separate pre-run protocol only if oracle tests pass
and smoke has admissible useful relations without systematic false ERROR.

Full development target: all 32 original cases, plus the eight-case mechanism
smoke includes disclosed prospective families; additional 16 remain disclosed
controls, never relabeled sealed. E0 is same-model/same-context historical cache
control; model-alias drift and representation changes are explicit limitations.

Report representation, source roles, semantic structure, role/identity/time checks
and final three-way decisions separately. Typed policy numbers are source-anchored;
general IS_TRUE/IS_FALSE are operators, not a learned business dictionary. Manual
semantic metrics use preauthored atomic annotations and must expose unmatched
or extra relations. UNKNOWN never maps to FALSE internally; binary metrics use
the separately labeled UNKNOWN→non-ERROR mapping.

Oracle truth and existing requirement evaluator are separate. Any violation-query
alternative remains a diagnostic ablation; NO_ERROR requires model coverage
opinion and closed extracted rules, never a completeness certificate.

New family holdout is conditional on a useful development signal. Freeze input,
gold, oracle annotations, prompts, code/scorer, model and limits before responses.
Authored labels remain an author-controlled reserve, not external blind evidence.
