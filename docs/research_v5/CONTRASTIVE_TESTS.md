# Tested invariants and remaining contrasts

The active adapter has 25 tests. Combined with the unchanged EvidenceGraph and
v11 core/obligation tests, **151 pass**. These are deterministic contract tests,
not evidence that a model generalizes to unseen business names or domains.
The original 85-test V4 audit and seven-phase zero-HTTP replay were completed
before implementation; their historical results are preserved.

| Contrast | Active evidence | Limit |
|---|---|---|
| Tool rename | `test_rename_and_alias_roles_are_not_business_tool_rules` | Oracle relationships supplied; no model rename experiment. |
| Different object/actor | Parameterized wrong-object/actor tests | Both native call and result roles must be supplied correctly. |
| Before/after | Late-check and second-current-call tests; nine V4 oracle controls | Complete process violation versus incomplete UNKNOWN is explicit. |
| Negative Boolean/missing prerequisite | False result and wrong/late check tests | Missing process is not false world authorization. |
| Tool attempt versus success | ATTEMPT vs actual Boolean outcome, truthy scalar rejection | Every required operational/outcome flag must be selected; names do not imply success. |
| User versus agent | User-check rejection, real h30 cause audit | Direct model still mistakes user/history scope. |
| Same-record identity | Alias joins, original native checker lineage checks | Semantic alias correctness is not guaranteed by ID validity. |
| AND versus OR | Conjunction/disjunction group test | No model preservation result; arbitrary NOT/complex nesting is outside active adapter. |
| Exception scope | Exempt, unresolved exception and missing policy anchor checks | Exemption itself is a semantic opinion; pilot omitted a prohibition that payment does not waive. |
| REQUIRE/FORBID/PERMIT | Permission cannot become prohibition | Model chose PERMIT for an explicitly forbidden condition. |
| Other versus same entity later receipt | Role-view tests | Different unique receipts may be excluded; same-entity later state must supersede. |
| Parallel call ambiguity | Both process and role-view tests | No receipt-pairing repair is inferred from convenient matching values. |
| ISO date/system time | Role oracle plus date checks | Other arithmetic and unsupported date formats remain unknown. |
| Proposal/read versus executed write | Real negative pilot and source-scope rejection | P3 selected a USER source as execution; automatic distinction failed. |
| Mutable versus explicitly immutable future fact | Active native checker rejects future evidence | Late immutable observation is not implemented/tested in the active adapter; earlier prototype is unvalidated. |
| Opaque effect declaration | No automatic effect proof in this pilot | No claim about new-name effect counterfactual or opacity robustness. |
| Multiple material claims | Whole-move target inventory, later-target aggregation test | Rule inventory and prose contradictions are still semantic/coverage gaps. |
| Transport 429/budget/cache | Single attempt, durable reservation, explicit stop, replay tests | Real run got four OK responses, no provider error. |
| Full originals/source integrity | Packet equality, tamper rejection and actual request hashes | Valid IDs do not establish policy meaning. |

The semantic contradictions in the real pilot are retained instead of fabricating
successful counterfactual results. No new model family holdout was launched,
because the required incremental development signal was absent.
