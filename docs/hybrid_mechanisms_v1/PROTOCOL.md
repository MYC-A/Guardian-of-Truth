# Frozen mechanism protocol

Independent branch `research/hybrid-mechanisms-v1-20261004`, base
`6035918cdcef6d5600aecfd91bc2f01a4d5cf73c`. Original datasets, labels,
production and earlier results are immutable. Machine protocol and original
source hashes are in `outputs/hybrid_mechanisms_v1/protocol.json`.

Before inference, freeze source, fixtures, historical D0 opinions and historical
AUTO request/response hashes; commit and push. Labels are in a separate scorer
fixture, never inference. Post-hoc source-based causal annotation is separate
from admission and binary labels. Four preselected known valid46 development
cases: original Telecom positive, bank057 proposal negative, airline23 whole
move/malformed payment positive, airline3 Silver conditional allowance negative.
The last is a conditional branch diagnostic, not a demonstrated general waiver.
The known validation set is not an independent holdout.

Researcher-assisted retrieval is disclosed. Telecom retains complete main and
suspension policy plus the broad native history. Banking retains whole policy
and two complete returned KB documents (business and personal checking), with
exact original offsets and all omissions. Airline sources retain whole policy
and all history. No head/tail clipping or silently shortened source is allowed.

I: same two cases, two available providers, four cells: I1 decision-first/original
labels, I2 decision-last/original, I3 first/explicit, I4 last/explicit. Only schema
property/required order and label paragraph vary within each provider. Mistral
strict schema and Ollama JSON-object plus schema in prompt are distinct decoding
modes. Record raw generated order; no order causal claim if actual order is not
honored. Single request per cell cannot establish a robust population effect.

Use I4 a priori for all subsequent cells, regardless of F1. K0/C0 are exact same
I4 base request and reuse that retained response. K1 adds only mechanical facts
whose original evidence is in K0. K2 uses generic greatest top-level typed operand
overlap to select compact comparisons and pair metadata; this is not semantic
identity certification. C1 derives potential actor/scope citation diagnostics
from sealed old D0 sources, never hardcoded history IDs. C2 exposes the original
judge opinion as an explicit anchoring diagnostic. Metadata without typed claimed
roles cannot prove a true semantic contradiction.

Separate Stage A extracts typed per-norm hypotheses with no final verdict.
FORBID condition means forbidden state established; REQUIRE condition means
prerequisite satisfied; applicability covers activating antecedents. Stage B
returns a separate model decision. Code separately aggregates typed hypotheses;
this is not source-qualified proof. V1 compares Stage A with I4 as a cross-pass
conditional diagnostic. V2 performs at most one semantic review, on the first
flagged case in fixed telecom/bank order. No flag means zero V2 calls. V3 narrow
code proof requires independently audited norm/action/state/exception closure;
oracle-assisted qualification is distinct from automated grounding.

R0 reuses only a byte-equivalent historical initial catalog and saved plan.
Its previously unexecuted final is a new I4 request. R1 gets that same initial
catalog, at most two planning rounds, eight distinct COMPLETE source reads and
one final judgment. Search snippets remain navigation. Gap status is hypothesis;
no model sufficiency statement certifies complete policy coverage. The cheaper
coverage control ranks policy by action lexical overlap and native result sources
by literal operand presence, with earliest/latest diversity and original call
pairs. No case ID, required receipt ID or business rule drives this runtime.

Global maximum: 36 inference HTTP attempts / 280000 verified-or-reserved tokens.
Allocation: 16 I + 8 K/C + 4 A/B + 5 R + 2 extra cases + at most 1 V2.
UTF8 full-body byte reservation plus 2048 template allowance and output cap;
verified usage refunds surplus. Unknown usage retains reservation and breaks
that provider. No retry, silent fallback, weights download or automatic budget
reallocation. Failures/BUDGET_STOP are unmeasured, never negative evidence.

Report admitted binary confusion/F1 on exact same case subsets, raw labels,
admission failures, explanatory cause, decision/reason consistency, source scope,
exception reasoning, actual retrieved fact, usage, latency and marginal costs.
Internal semantic UNKNOWN maps to binary zero explicitly. Technical failures
have null semantic decision and are listed separately with complete denominators.
No aggregate valid46 improvement or holdout generalization can be claimed from
these four selected cases. No full Hybrid architecture implementation is in scope.
