# Predeclared hypotheses

H1: explanation-before-decision can reduce wrong labels despite correct reasons.
Evidence requires the provider actually generating the requested field order;
schema request order alone is insufficient.

H2: explicit ERROR/NO_ERROR/UNKNOWN meaning can reduce label/meaning mismatch.
An improved label with a wrong cause is not causal recovery.

H3: Gemma may differ from Ministral. Provider/decoding differences and one sample
per cell prevent an architecture-independent model ranking.

H4: raw code facts may help reasoning or distract. K1/K2 have the same source
universe as K0; raw pairing/date/equality do not prove ownership or applicability.

H5: factual citation metadata may help independent reassessment; exposing the
old conclusion can anchor. C1 cannot claim a certified conflict when the old
schema lacks claimed actor/currentness roles. Bank negative is a pressure control.

H6: gap-guided retrieval may discover missing early facts under the same eight
reads. Compare with frozen old one-shot selection and simpler coverage-aware
selection. Independently discovering a source is separate from correct semantics.

H7: typed consistency checks may detect contradictions, but cannot establish
normative truth. Cross-pass comparisons differ from same-answer consistency.
Qualified code proof must not obtain semantic qualification from model booleans.

Decision rule: prefer the simplest mechanism supported by comparable source-based
results. Unsupported/unmeasured mechanisms remain explicitly marked. A new
independent holdout is needed before population F1 or production claims.
