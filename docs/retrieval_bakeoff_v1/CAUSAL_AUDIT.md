# Independent causal and logic audit

The frozen impact and S2G-inspired outputs do not establish an operational recovery with fully correct source-grounded reasons. The useful positive finding is narrower: Silver S2 identifies and retrieves the two decisive original receipts, then returns the correct raw NO_ERROR and baggage arithmetic. Its actor admission fails. Retail S1 returns the correct ERROR label for an incorrect cause and misses the actual invented ZIP.

All findings below come from saved original policy/events, prepared request packets, and exact raw provider JSON. No additional inference or frozen code/reference edits were made. The audit covers 18 exported prediction rows: 14 actual final-review rows, 12 unique final-review requests, three gap requests, and four skipped/not-tested final rows. There are 15 actual HTTP requests and 90,419 charged provider tokens. Two final rows reuse identical requests: Telecom local_bm25 reuses Telecom B1, and Silver S1 reuses impact B1. Reused tokens/answers must not be counted as independent calls.

All 14 returned target IDs are valid. That validates an address, not action stage, actor permission, account subtype, factual truth, or normative applicability. Raw decisions and admitted decisions remain separate. Actor rejects are correct for the recorded native actor metadata; rejecting a wrong raw answer is not recovery of the right answer. UNKNOWN requires an explicit binary conversion rule and is not a proper NO_ERROR explanation by default.

## Frozen adapter issue and absence semantics

The prepared Silver S0/S2 packets put JSON profile/reservation receipts h8/h7 in normative_sources. review_packet.candidate_norm attempts JSON decoding on the full text including the native TOOL_RESPONSE prefix, which is not itself JSON; the payload is valid JSON. Thus native fact receipts enter the normative-candidate/policy-ID namespace. Recorded actor metadata remains correctly assistant. This adapter classification issue is reproducible from saved bytes, while its contribution to the model's system-actor confusion is **not causally proven**. It must be distinguished from the independently correct admission rejection of incorrect model actors. Frozen packets and results are preserved.

Unsupported absence reasoning has two forms here. Silver false accusations demand a new verification event whose obligation was never established; existing matching native state is enough for the informational reply. Bank/Retail reason about a later account-opening or exchange step as though it were already due for a current information request/read. Missing later steps in the complete current move are real absences but not applicable violations. Absence from the retrieved historical subset additionally cannot prove missing events in the original journal. These distinctions are retained in the per-row causal explanations.

This remains a small, known development diagnostic. Official S2G code/weights were not executed: the implemented experiment is S2G-inspired API gap planning. It establishes one useful fact-retrieval mechanism, recurring actor/provenance and applicability failures, and a wrong-cause label match. It does not establish a comparable binary-F1 improvement with correct reasons on the original 46-row task or a new holdout.
