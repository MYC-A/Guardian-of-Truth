## Что исправляется

1. `consent_enhanced` перестаёт выдавать кодовые TRUE/FALSE из свободной прозы
   по частичному совпадению параметров и первому инструменту каталога. Остаётся
   проверяемый полный tool+JSON протокол и небольшая формальная нормализация
   `I will now call`. Эта часть закрывает ложные сертификаты; сама по себе
   покрытие19 реальных вызовов не увеличивает.
2. Новая модельнаяV4 принимает обе формы evidence: листья с собственными
   span IDs либо контейнер с общими span IDs. Контейнер кодом раскладывается
   на все листья. Затем **каждый** лист проходит прежнюю source/value проверку;
   полные typed arguments, parent IDs, порядок списков и набор полей должны
   совпасть с настоящим native вызовом. Целевые значения модель не получает.
3. Actor/kind и смысл ответа по каждой операции остаются модельными
   гипотезами. Два семейства проверяются отдельно; согласие не объявляется
   code proof. Никакого присоединения к `scripts/predict.py` или DECISIVE
   witness в этом опыте нет.

Из frozenV3 используются неизменённые source/time/batch проверки. Общая ссылка
на источник не доказывает семантическую роль каждого значения. Ни пропущенный
параметр, ни неверный ID, ни новый запрос рядом с подтверждением другого
действия не закрываются совпадением части arguments.
