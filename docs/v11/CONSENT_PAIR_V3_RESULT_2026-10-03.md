## Остаточные ограничения и следующий шаг

1. Контейнер с общей ссылкой можно разложить кодом на листья, затем независимо
   проверить каждое значение и полное совпадение структуры с native call.
   Это новая версия, а не изменение оценкиV3. Source occurrence всё ещё не
   доказывает правильное значение поля/сущности: семантическая привязка остаётся модельной.
2. Неявный год, сохранённые части маршрута и предыдущие receipts не достраиваются.
   Полные native arguments могут быть больше описанного пользователю изменения.
3. Latest-pair не покрывает старое отложенное предложение или новый запрос
   багажа рядом с подтверждением изменения рейса. UNKNOWN здесь нельзя
   превращать в TRUE по одному ID брони.

gold-меток согласия. Найденные TRUE проверяются отдельно по первоисточникам.
