# Исправление свидетеля подтверждения V11 (до пилота)

API V11: 0. Gold не открывался. Дополняет `PREPARATION.md`.

Найдены ошибки, дававшие ложное `RESOLVED FALSE` (ложная находка «нет
подтверждения») или ложное `TRUE`:

- Повтор подтверждённого действия в целевом ответе («I will now apply … X»)
  стирал более раннее «Yes». Теперь берётся последнее описание с ответом
  пользователя; последующий текст без вопроса согласие не отменяет, новый
  неотвеченный запрос подтверждения даёт UNKNOWN.
- «No problem, go ahead» / «Нет возражений, подтверждаю» считались отказом.
  Такие обороты не являются отказом; решает остаток фразы. Фильтр оговорок
  расширен (don't, wait, cancel, подождите, отмена).
- `X` привязывался к `X-1` / `X.2`. Соединённые символы ID теперь часть токена.
- Идентичный повтор целевого вызова (например, после timeout) сохраняет
  согласие; любой другой native call по-прежнему его расходует.
- Если разговор продолжился после ответа пользователя, согласие не
  переносится: UNKNOWN.

`prepare.py --witnesses` на новом коде: из 84 вызовов изменилась только
причина одного UNKNOWN (telecom h20: `conversation_continued_after_reply`
вместо `intervening_call_requires_new_action_binding`). Статусы и выборка
из 20 не изменились. `witness_inventory.json` перегенерировать этой командой.

Хэш `witness.py` в `pilot_freeze.json` обновлён. Тесты V11: 54 passed
(`tests/test_policy_table_v11_confirmation.py`, 13 новых).
