## C1–C5

Общие признаки ключа `{key}`: совпадение со значением дочернего `id`/`*_id`,
≥4 последовательных цифры либо меняющиеся ключи одной структуры между
результатами одного инструмента. Массивы `*`. Без доменных словарей и усечения
каталога по лимиту: цель ≤120 путей проверяется и дефицит сообщается.
Аргументы засвидетельствованы декларацией. Состояние — декларацией результата
(если есть) и фактическими результатами. Типы и происхождение сохраняются.

Время — явная фраза политики или последний однозначный результат инструмента
текущего времени; неизвестная зона не угадывается. Подтверждение — только
трёхзначный кодовый witness: привязанный к аргументу запрос подтверждения,
последняя реплика пользователя, явное согласие/отказ или доказанное отсутствие
реплики между описанием действия и текущим вызовом. Общий ru/en лексикон.
Проверки: ≥12 синтетических диалогов; 20 результатов на историях по seed
20261003 проверяются вручную как парсинг, без оценки детектора.

Компилируются **все** объявленные инструменты и TRANSFER/REFUSE. Один запрос
на инструмент, trigger устанавливает код. Модель возвращает отдельные атомы,
не выбирает trigger; полный текст политики, компактный каталог, без enum-схемы.
Необходимое A OR B — один ANY_OF. Для `*`/`{key}` обязателен TARGET/ANY/ALL;
TARGET требует проверяемой связи аргумента с ключом/полем записи. Пустая
коллекция даёт UNRESOLVED, в том числе у FORBIDS, а не доказанное нарушение.
Для отрицательных условий нет превращения неизвестного значения в FALSE.

Согласие: policy + trigger + modality + нормализованное выражение / prior_call
+ quantifier + binding. Числа Decimal, singleton-in равен eq, порядок ANY_OF
и списков несуществен, != эквивалентен not_in. Clause IDs объединяются,
но не участвуют в ключе; каждый ID должен существовать. Лишние атомы не мешают
согласовать общий атом. DECISIVE = 3/3, ≥2 семейства; SHADOW = 2/3.
**Асимметрия:** все валидные исключения любого пропозёра того же trigger
объединяются для каждого согласованного атома. Это может уменьшить recall,
но не разрешает новое срабатывание. TRUE/UNRESOLVED исключение подавляет его.

Новые модули изолированы от V10; старые policy-table тесты сохраняются.
Finding: необходимый атом FALSE или запрещённый атом TRUE, без подавляющего
исключения. Финал: **old direct ERROR OR DECISIVE finding**. SHADOW,
UNRESOLVED и отсутствие правила не меняют old direct. Speech-act без
надёжного witness остаётся UNRESOLVED; ручная разметка актов не добавляется.

## Мутации, замер и Track B

Мутации строятся из исходных историй, независимо от таблицы: M1 удаление
привязанного подтверждения и ответного хода, M2 удаление read-пары при
исчезновении единственного источника ID, M3 замена аргумента на ID другой
сущности того же типа из истории. Их число не дополняется искусственно.
Отдельная policy-level аннотация: требуемое X и исходная цитата, составленная
без кейсов. Применимость и предпосылки каждого мутанта проверяются; один
изменённый шаг не означает NO_ERROR всего контроля. Считается конкретный
атом/обязанность, а whole-detector — только доказанное ERROR и инвариантность.

Основной замер — сохранённые direct ответы + новая таблица, никаких новых
direct API. Сначала запечатаны все предсказания, потом открывается gold.
Для каждого изменения — атом, исходные пункты, witness. SHADOW counterfactual
показывается отдельно. Неуспех не запускает настройку по меткам.

После основного замера Track B: неизменённый прежний direct prompt на всех
46 входах, GPT-OSS120b high и лучший другой модельный family из пилота.
Один прогон каждого. Выбор допустим только при FP≤baselineFP и FN≤baselineFN−2.
При равенстве — FN, FP, фиксированный порядок кандидатов. Комбинация лучшего
прошедшего direct с таблицей считается отдельно. Это размеченный эксперимент.

## Уточнения до окончательного freeze (2026-10-03)

Исправлено до пилота и до просмотра gold; семантика C1–C5 не меняется.

- **Подтверждение.** FALSE (позитивная улика нарушения) только в трёх
  узких случаях: после первого привязанного описания нет ни одного хода
  пользователя; последний привязанный в текущем сегменте явный вопрос о
  подтверждении (`?` + confirm/подтверд/proceed) остался без ответа и ни одно
  прежнее привязанное описание не было подтверждено; ответ на последнее
  отвеченное привязанное описание явный отказ («нет», «no», «не надо», «do not
  proceed»… с пустым вежливым хвостом). «Cancel it», «Отмените», «No problem»,
  «Нет, всё верно», «Не против» не отказ. Повествование после «да» («сейчас
  отменю X») не новый вопрос. Идентичный повтор вызова, `X-1`/`X.2`,
  продолжение разговора: см. `CONFIRMATION_FIX.md`. Иначе UNKNOWN.
- **Якоря состояния.** Скалярный `state.<read>./path` привязывается только по
  ID-аргументам цели, с которыми вызывался этот read-инструмент (иначе
  `payment_method_id` у return делал `get_order_details./status` вечным
  UNKNOWN). Чужая сущность по-прежнему исключается.
- **Пробы.** Проба 0 temperature 0 (отпечаток прежний); запасные пробы той же
  модели temperature 0.7, иначе они не независимы. Повтор JSON при resume
  берётся из записи, второй retry не делается.
- **Freeze** покрывает все загруженные модули `guardian_truth`, скрипты V11,
  PLAN, входы и прежние direct предсказания, V10 мутации, аннотации,
  манифест мутаций и тесты V11.
- **`measure.py`**: `mutations` (детерминированно, seed 20261003) →
  `predict` (только после закоммиченного final freeze, без перезаписи, seal) →
  коммит → `score` (gold читается только если predictions и seal совпадают с
  HEAD). Прежний direct: ERROR 15 / NO_ERROR 31.
- **Аннотации** `outputs/searh_23/v11/annotations.json` составлены только по
  тексту политик (airline, retail); telecom и banking не аннотированы, их
  мутанты NOT_ANNOTATED и в знаменатель recall не входят.

## Расходы и эксплуатация

**Отдельный общий V11 журнал: 450 HTTP / 3 000 000 токенов.** GET models тоже
считается HTTP; прошлые расходы не обнуляются, но в V11 не входят.
Usage сохраняется; при неизвестном расходе резервируется верхняя оценка.
402/429 выключает только провайдера без повторов; остальные продолжают.
Авторизационная ошибка или исчерпание общего бюджета останавливает весь V11.
Одна повторная попытка только для синтаксически невалидного JSON, тот же
промпт, новый receipt. Невалидные атомы отклоняются отдельно; raw сохраняется
до разбора. Нет retries других ошибок и бесконечного polling.

Старые четыре исторические seal-ошибки не исправляются. Новый красный тест
исправляется максимум за две попытки, иначе остановка. Новые ветка/worktree
и серверная папка изолированы от других агентов. SSH `new`, основной venv;
без изменения SSH, драйверов и серверных сервисов. Одноразовые batch идут
foreground через SSH по уже согласованному исключению operating guide.
`scripts/predict.py` и сервис не меняются. Важный код/результаты уходят в Git
и локальную копию. Итог `docs/v11/RESULT.md` ≤2 экранов, честные ограничения.
