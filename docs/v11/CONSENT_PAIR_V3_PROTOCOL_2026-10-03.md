# Согласие: дерево параметров и исполнитель каждой операции

Предыдущий полный frozen v2 (`75536434`) дал TRUE2/19, подтверждённых независимым
source-only просмотром Astra. Его алгоритм, ответы и метрики сохраняются.

## Изменения нового опыта до API

1. Вместо arguments плюс параллельный inventory JSON pointers — одно дерево:
   каждый лист содержит `{value, span_ids}`. Код восстанавливает аргументы и
   пути. Список требует evidence каждому элементу; групповой shortcut не принимается.
2. Kind/executor относятся к отдельной операции, а не всему сообщению. Автор
   согласия и исполнитель бизнес-действия — разные роли. Просьба подтвердить
   действие ассистента не является USER_ACTION. Условие «после вашего согласия»
   отличается от ещё не выполненного внешнего условия.
3. Astra воспроизвела дополнительный дефект изоляции: некорректный tool вроде
   списка или неизвестного имени считался посторонним. Только в новом v3 такой
   отклонённый план получает неизвестную область и блокирует TRUE.

Из v2 используются неизменённые проверки native target, source spans, типизированного
совпадения полного arguments и последовательности/расходования пакета. Отсутствующие
поля не достраиваются, даты/неизменяемые сегменты/receipt не объявляются согласованными.
Источник bool/пустого контейнера по-прежнему требует точного JSON-литерала; появление
тех же значений внутри всей строки JSON не автоматически даёт поддержку каждому полю.
Это может сохранять UNKNOWN, в том числе на новом положительном вложенном контроле.
