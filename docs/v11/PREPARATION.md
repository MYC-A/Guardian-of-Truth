# Проверка подготовки C1–C5

Частично: каталоги **301/959/101/43 → 100/74/67/30**, V11 API **0**.

Пути с конкретными ID отсутствуют во всех четырёх каталогах. Скалярные
листья, массивы и пустые объекты — проверяемые значения; непустые объекты
служат пространствами имён. Это общее изменение представления, без отсечения
путей для достижения численного лимита. Изменяющиеся однотипные ключи
скалярных карт тоже сворачиваются; наличие постоянного поля той же структуры
защищает обычную запись от такого сворачивания.

Старые V10 модули не изменены. Новые C1–C5 находятся в `policy_table_v11`.
Agreement пересчитывается из сохранённых предложений при загрузке;
исключение валидного источника учитывается даже при невалидном основном атоме.
Порядок boolean/membership списков не влияет на согласие; порядок массива,
сравниваемого целиком через equality, сохраняется как часть его значения.

## Ручная проверка свидетелей

Seed **20261003**, 20 случайных вызовов из 84 write/неустановленных вызовов
в историях и текущих ответах. Gold не открывался. Список и точные контексты:
`outputs/searh_23/v11/preparation/witness_review_20.json`.

Индексы проверены: **0–19**. У 4 и 17 — прямое «да/подтверждаю» после
описания со значениями аргументов; TRUE обоснован. У 0 длинное явное согласие
ошибочно считалось UNKNOWN из-за произвольного ограничения длины ответа:
ограничение убрано для всех языков; общий фильтр условности/отрицания сохранён.
У 2 согласие начинается с ID, а не с утвердительного слова: консервативный
UNKNOWN оставлен, этот более сложный разбор не объявляется решённым.
У 8 и 13 между описанием и вызовом есть другие native calls; привязка
подтверждения к новой операции не доказана, UNKNOWN оправдан. У 19 аргументы
не удалось разобрать; нет кодовой привязки. Остальные 1,3,5,6,7,9,10,11,12,
14,15,16,18 не содержат буквального значения ключевого аргумента текущего
вызова в последнем описании: UNKNOWN безопасен, но свидетель узкий.

Время airline читается из политики с EST. В banking найден настоящий
plaintext-результат инструмента: `The current time is ... EST.`. Добавлен
общий разбор полного литерала/этой фразы только у инструмента текущего времени;
JSON не является обязательным форматом времени. Тест отдельный, без меток.
Неизвестная зона и последний неполный результат остаются UNKNOWN.

Это проверка парсинга, **не** измерение precision/recall. Подтверждение
ограничено буквальным совпадением аргумента, общим ru/en лексиконом и
консервативной остановкой цепочки на промежуточном вызове. Обёртки с JSON
в строковом аргументе не разворачиваются в новый тип инструмента.
