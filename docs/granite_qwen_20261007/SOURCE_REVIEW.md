# Что означают семь архивных дополнений к Qwen

Отдельный агент сравнил все7 archive-only addedTP и1 addedFP с original valid46 и точным historical bound_pair. Все7 responses доставлены целиком, все7 prompts усечены до4800символов. Native Granite выдаёт только score, поэтому это **не семь установленных правильных причин**.

Все перечисленные классы смысловые/процедурные, а не malformed JSON. Однако row-level TP не доказывает, что Granite обнаружил именно этот механизм, особенно при отсутствии решающей нормы в доставленном документе. Названия tools/IDs здесь только диагностические ссылки, runtime получает native groundedness contract, без специальных правил.

AddedFP retail87 t6: полный источник поддерживает предложение изменений с запросом подтверждения. Из окна пропущены три pending-order IDs и USER request использовать найденный адрес. Это правдоподобная packing-induced grounding ошибка, но конкретная причина model verdict без controlled intervention не установлена.

Следствие для архитектуры: archive OR promising по labels, но комбинация должна сохранять source coverage и различать модельную оценку риска от полного policy proof. Превращать positive score в формальный сертификат нельзя. Протокол нового reproduction не меняется после этого review; source-aware/full-context вариант сейчас не запускается. Метки и исторические ответы сохраняются.
