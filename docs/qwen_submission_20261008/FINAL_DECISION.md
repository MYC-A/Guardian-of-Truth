# Решение о пакете и границы проверки

Для пробной отправки выбран существующий Qwen B2/R_fix/v6fix с Q8_0 и8 слотами.
Промпты, веса и лимиты ответов сохранены. Вариант16slots+FA+batch8192 не показал
ускорения в одной полной проверке и добавил1FP; в default не включён.

Свежие полные valid46:8slots14TP/0FP/9FN/F1.7568;16slots14TP/1FP/9FN/F1.7368.
Исторический B2 был13TP/1FP/F1.7027. **Нельзя объявить прирост качества относительно
истории:** это разные модельные ответы без одинакового контроля и repetitions.
valid46 давно development, а не blind оценка конкурсного качества.

Исправлен общий дефект обёртки: неисполненная optional pre-analysis injection
не отменяет валидный terminal reviewer после заявленного fallback. Ни ID, ни
gold, ни домен не участвуют в исправлении. Неисполненные actual primary requests
по-прежнему не производят отрицательных labels. Исходные live phases завершились
exit1; corrected projections сохранены отдельно. Полный exact-request raw replay
на Windows восстановил179/179 запросов и все final binary/owner/accusation.

Архив30.45GB собран на сервере, SHA зафиксирован; локальная копия наA ещё требует
завершения передачи и проверки. Исходный GitHub branch не содержит весов/архива.
Инструкции передачи: UPLOAD.md. Самостоятельного submission в аккаунт не было.

Dockerfile подготовлен, но реальный Docker engine здесь отсутствует. Проверены
реальный model runtime на A100, Linux ZIP permissions/loader, offline install,
native imports, empty public CLI и точная обработка сохранённых replies. Это
не заменяет фактический Docker build/run и не доказывает runner compatibility
на неизвестной платформе. Для Guardian официально описан unpacked source archive.

До первой отправки нужно иметь READY local archive. Платформенный запуск затем
даст свидетельство о реальном input size, environment, time limit и score.
30min для548 строк не обещаны;548 не подтверждены как размер всего входа.
Длины и eligibility дополнительных проверок также неизвестны.

Новых универсальных гарантий или качества hidden test не заявляется. Общая цель
сборки и передачи ещё не завершена, пока локальный ZIP не проверен; публикация
кода и отдельного набора receipts уже выполнена.
