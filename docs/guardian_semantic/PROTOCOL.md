## Отбор на frozen (по dev, до frozen)
Вариант проходит, если: исправляет ≥2 из 6 известных пропусков с верной причиной (цель = золото и маркер причины в тексте,
плюс ручная самопроверка), 0 новых FP на 4 контролях, нет технических сбоев >1 строки. Прирост засчитывается механизму
(blind / Python), только если он больше прироста его контроля равного числа вызовов (E1 / PyCtl) на тех же строках.
## Метрики
TP/FP/FN/TN, P/R/F1 по итоговому решению; по семействам; верность причины (авто + ручная); вызовы/токены/строку (записи),
фактические затраты и латентность (журнал); для Python: заметил ли нужду, выбор данных, корректность кода, использовал ли результат.
Повторы одной строки не считаются независимыми задачами; при температуре 0 повтор = другой attempt-ключ, а не новая выборка.
Устойчивость (переименование ID + перестановка записей) — только если останется ≥20 запросов, иначе NOT_EXECUTED.
