# Decision: LOCAL_MECHANISM_SIGNAL_WITH_UNRESOLVED_OUTPUT_AND_RETRIEVAL

**B independently recovers the correct Telecom cause and emits ERROR. A/C recover
the explanatory cause but emit an inconsistent NO_ERROR.** Retain the small
targeted reviewer as a research hypothesis; do not build or adopt Guardian Hybrid.
No comparable valid46 F1 gain or independent holdout advantage was measured.

1. **Correct cause without D0?** Yes in all three explanations; only B satisfies
   the full original cause/decision conjunction. Source q7, current t0, original
   h9/h10 line L1002, contract_end_date 2025-01-31, explicit system date 2025-02-25
   and payment-independent prohibition are all correctly identified. A/C remain
   wrong final decisions; their prose is not used to flip labels.
2. **Did verified code facts help?** B aligns final verdict with the cause in this
   one sample. A already finds the same cause, so there is no evidence that facts
   revealed a missing rule. A systematic causal benefit is unestablished. Code
   facts certify raw equality/dates/pairing only; aliases and norm scope remain
   semantic interpretation.
3. **Did contradiction notification help?** No demonstrated benefit. C again
   emits an inconsistent final NO_ERROR. The original historical/user payment
   allegations are not repeated; nevertheless its final decision is unreliable.
4. **Negative controls?** Read-only and future-date copies avoid the intended
   false accusation. Payment variation was BUDGET_STOP, so full control coverage
   and payment invariance are unestablished. These are disclosed author-controlled
   copies, not official negatives or independent test families.
5. **Automatic discovery?** The one source-selection plan finds relevant q7/q17
   normative text but reads no history, missing the actual line/contract receipt.
   Complete evidence discovery fails in this plan; final semantic review was not
   called due to budget. This does not prove a broader adaptive retriever fails.
6. **What obstructs the mechanism?** Two observed boundaries: final decision can
   contradict correctly grounded explanation, and the limited planner overreads
   policy without retrieving target evidence. No code inversion was found; raw
   replies and offline replay show the contradiction originated in model output.
   Whether schema order, label definitions or provider/model behavior causes it
   is not isolated. Some auxiliary wording also confuses prohibited state with
   an unperformed check; do not turn that into an invented procedural rule.
7. **Minimal next experiment?** One separately frozen small 2x2 interface test:
   decision first/last crossed with original/explicit label definitions. This
   separates serialization order from label semantics. Keep model, source-complete packets,
   budgets and scoring comparable; include positive and negative source-clear
   cases and count explanation/label consistency independently. This tests the
   observed output gap without changing historical replies or growing architecture.
8. **Continue Gap Controller/targeted reviewer?** Targeted semantic recovery has
   a local oracle-assisted positive example. That supports further small tests,
   not deployment. The contradiction-trigger itself has no incremental signal;
   a full Gap Controller is unjustified. General retrieval, robust controls and
   unseen-domain correctness still need evidence.

The outcome does not meet an unqualified strong-positive-mechanism claim: one
correct oracle-assisted B, two inconsistent labels, incomplete payment control
and no completed automatic final judgment. It also is not an all-arm semantic
failure: original normative understanding was demonstrably present in A/B/C.
The result is narrower and useful precisely because those boundaries are separate.

Six inference requests charged **45,089 tokens**, below the 10-call/60,000 cap.
All remaining stops are explicit technical outcomes. Source freeze, raw replies,
case annotations, budget ledger, independent reviews and offline replay are
preserved. Production, prior research phases and original labels are unchanged.
Stop this phase here. The proposed next interface experiment is not executed.
