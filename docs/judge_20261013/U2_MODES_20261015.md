# Режимы контекста legacy / u2 / u2_dense (15.10.2026)

Родитель `4da76c0ac3a1f7074a10830fceeccd094e937c44`. Модель, веса, exact scoring, квота 30% от оцененных строк,
overall@on и один вызов на строку не менялись. Режим: `context_mode` в конфиге стадии, по умолчанию `legacy`.

| Режим | Контекст | Откат по строке |
|---|---|---|
| legacy | bounded builder | - |
| u2 | пакет U2 (BM25, ID, давность) + весь каталог | legacy:<причина> |
| u2_dense | то же + MiniLM-L12 как сигнал ранжирования | u2(dense_fallback:<причина>) |

## Гарантии кода

- Порядок уступок во всех режимах: история, подсказки, затем ответ (head + tail до MIN_RESPONSE_CHARS), затем политика.
  Раньше ответ заранее резался до 30000 символов и терял середину. Любая обрезка ответа: `response_trimmed=true`.
  Это меняет и legacy для ответов длиннее 30000 символов.
- Плановый cap и контекст модели разделены: `over_cap`, лишние токены в прогнозе времени, TOO_LONG сверх контекста.
- Сверка парсеров пособытийная: вид, роль, инструмент, аргументы, содержимое и явный статус результата
  (тег, префикс [TAG], атрибут status); статус, выведенный только из слова Error, не считается расхождением.
- Пакеты: отдельный CPU-процесс, run id, SHA256 stage_input и хэш строки; остановка в finally и перед os._exit.
- Упаковщик: замыкание импортов (отсутствующий модуль останавливает сборку); энкодер только закрепленный
  и полный (tokenizer, sentence_bert_config, сверка ENCODER_SOURCE.json), иначе ошибка сборки.

## Границы

GPU_UNTESTED. Прирост F1 и время упаковки на реальных строках не измерены. Рекомендуемый default: legacy
до парного A/B legacy/u2/u2_dense на одинаковых строках и настройках.
