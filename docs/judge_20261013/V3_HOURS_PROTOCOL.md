finish in hours, then asked for a concrete deadline. Target: six hours from this
amendment, including remaining preparation, technical pilots, training and checks.

to fabricate independent scenarios. Do not spend days simply to reach a count.

First measure actual context lengths and GPU training time/memory. Main priority:
source-grounded data targeting scope/consent/eligibility and faithful tool-result

source hashes, groups, token counts and measured throughput, before quality/eval

metrics to select a favorable reduced data subset. Report exact updates, epochs,
rows, sources and missed original objectives, never call a partial epoch complete.

long-input, hard-negative, annotation/human-review, contamination or runtime
requirement remains unmet. Shortened or incompletely reviewed experiments are
EXPLORATORY_ONLY, not evidence of fully completed original v3 or permission for
a ZIP. Record human review as unavailable, not performed by another model.

failure and a recommendation to keep the submission is a valid six-hour outcome.
