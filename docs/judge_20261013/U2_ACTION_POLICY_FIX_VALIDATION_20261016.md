# Проверка исправленной интеграции U2, 16.10.2026

Основа — присланный `u2_action_policy_v3_20261016.zip`, SHA256
`1f0f11060c54c40164250a940255d27e53a9d79fcc1126f60efc853646083d2e`,
поверх базы `9573f9b05f25b16740ca9be0a5126e518b49ce62`.

V3 принёс исправленный тест реального энкодера, прямые смещения цитат, распределение
резерва между действиями, итоговое покрытие правил и сокращение слишком длинного
вспомогательного пути заголовков. В локальной интеграции дополнительно исправлены
приоритет прямых совпадений перед синонимами и строгое соблюдение окна энкодера.

## Поведение

- Синонимный раздел рассматривается только при отсутствии прямого совпадения для этого
  действия. При распределении резерва сначала обходятся прямые разделы, затем синонимные.
  Это порядок поиска, а не доказательство применимости политики.
- Непомещающийся кусок доразбивается до помещающегося минимального. Если это невозможно,
  `EncoderWindowError` приводит к обычному U2 с явным `dense_fallback`.
- Вспомогательный путь заголовков может сокращаться только для эмбеддингов. Исходные
  цитаты в пакете остаются дословными. Пропуски сообщаются, полнота разделов вычисляется
  после окончательного выбора источников.
- Исследовательский отчёт берёт смещения из `context_for(with_spans=True)` и не ищет
  повторяющийся текст заново. Эти диапазоны описывают выбранные источники; повторно
  показываемые заголовки ролей и диагностические маркеры в дифф источников не входят.
- Синонимы остаются диагностической опцией. Рекомендуемый экспериментальный профиль их
  не включает. Production-конфигурация не изменена, режим по умолчанию — `legacy`.

## Локальные проверки

197 тестов на Windows: 193 успешны, 4 пропущены из-за POSIX process groups, ошибок нет.
Реальный MiniLM участвовал в тестах, включая CJK-текст, длинный путь заголовков,
сохранение последнего утверждения и точное ограничение окна.

Новые регрессии используют искусственные имена действий и политик, без gold labels.
Они проверяют: приоритет прямых совпадений, сохранность их резерва при появлении
синонимных разделов, правильный адрес второй одинаковой реплики, именованный fallback
для невозможного окна и покрытие текста реальным токенизатором.

## CPU-подготовка на valid46

Ввод один и тот же для всех профилей, SHA256
`8e730cc999a6cf07c3f17f273300a17ce16539c5b6166885e74b41e93cfc47ba`.
В поиск передавались только prompt/response. Ревизия MiniLM —
`e8f8c211226b894fcb81acc59f3b34ba3efd5f42`, Torch 2.10 CPU, Transformers 5.8.
Бюджеты 5 секунд на строку и 300 секунд на проход; у каждого dense-профиля свой
прикладной кэш, ОС-кэш/импорты могли быть тёплыми. Время загрузки измерено отдельно
в JSON, таблица показывает только CPU-проход подготовки.

| Профиль | CPU-проход, с | Dense fallback |
|---|---:|---:|
| u2 | 3.108 | — |
| u2 + action | 2.990 | — |
| u2 + action + synonyms (диагностика) | 3.172 | — |
| u2_dense без новых опций | 53.388 | 1 |
| dense_v1, прежний набор опций на новом коде | 13.964 | 0 |
| dense_v2, рекомендуемый экспериментальный профиль | 15.247 | 0 |

Рекомендуемый экспериментальный профиль задаётся явно:

```json
{
  "context_mode": "u2_dense",
  "u2_action_policy": true,
  "u2_dense_fusion": "remainder",
  "u2_dense_scope": "policy",
  "u2_dense_query_chars": 400,
  "u2_dense_passage_pieces": true,
  "u2_action_synonyms": false
}
```

Результаты исполнения:

- Без новых опций 46/46 контекстов совпали с прежним U2 из опубликованного эксперимента.
- У dense_v2 изменились 23 контекста относительно U2. Это число изменений, не число улучшений.
- У dense_v2 обработаны 261 query piece и 2645 passage pieces за весь проход;
  `unfit_queries=0`, `unfit_passages=0`, `truncated_texts=0`.
- Все шесть сохранённых диагностических цитат присутствуют у u2+action, dense_v2 и
  dense_v2+synonyms. Условия отмены в строке 6 не теряются при добавлении синонима;
  правило другого варианта товара в строке 29 также сохраняется.
- Проверены 590 добавленных/удалённых диапазонов: их тексты точно равны срезам prompt
  по указанным смещениям. Отдельная регрессия проверяет правильность адреса повторной цитаты.

Проверки цитат выбраны после предыдущих экспериментов. Они служат регрессиями, не являются
независимой оценкой evidence recall, основанием выбора порога или оценкой прироста F1.
53.4/15.2 секунды относятся к этому CPU-прогону и не означают такое же ускорение Qwen.

## Ограничения

Резерв контекста ограничен. Например, на строке 3 раздел отмены содержит 4 из 6 блоков,
а не весь раздел; результат честно отмечается PARTIAL. Приоритет прямых совпадений
исправляет конкретное вытеснение, но не доказывает универсальную полноту всех правил.
Разделы без подходящего заголовка и ответы без вызовов также не получают этого якоря.

Qwen не запускалась. GPU_UNTESTED: F1, время полного запуска на A100 и качество выбора
всех 23 изменённых контекстов требуют отдельного парного прогона. Полный ZIP здесь
не пересобирался. Библиотеки, веса, квота положительных и конфигурация judge сохранены.
