## Повторы, устойчивость и метод

Три сохранённых strict-final replay на520 строках: текст и хеши token IDs
совпадают. Из1560 попарных разностей sd_obs=.286793676 log-odds, средняя разность

Применение этого sd к итоговому max — заявленное приближение чувствительности.

При измеренном sd все кандидаты укладываются в средние3% изменений решений на
каждой точке обоих главных наборов. Максимумы по точкам:
R1 —1.146%/0.668%, R2 —1.060%/2.681%, R3 —1.431%/1.455% (397/191).
Обязательная сетка sd .05,.10,.25,.50,1.00 также посчитана,200 общих реализаций
шума на sd. В JSON записаны изменения F1,95-й перцентиль доли изменённых решений
и доля ходов около границы; положительный исход (c) не заменяет невыполненное (a).

Отдельный исходный4B Transformers audit:78/78 точных совпадений, наблюдённый
разброс0. Это другая модель/runtime и не оценка шума будущего v3 адаптера.

Пять внешних и пять внутренних folds по conversation, не по отдельным ходам.
R2/R3 выбираются только по внутренним folds; внешний gold не участвует в выборе
порога, Platt или EM. EM использует cross-fit likelihood ratios для одной новой
батчевой доли. Это приближение набора разных калибраторов; предполагается label
shift, который не гарантирован при смене домена.

1000 парных bootstrap по conversation для каждой точки397/191, включая группы
только с TN. После выбора групп повторён class-weighted ресэмплинг; native
использует сам выбранный групповой пул. В bootstrap не переобучались пороги и
калибровка: CI условны на зафиксированных cross-fit параметрах, не включают
неопределённость повторного выбора модели. Эти ранее просмотренные и
пересекающиеся наборы не стали независимым holdout.
