# S2: ограниченный структурный кандидат, до его оценки

19.10.2026. S raw-flags выявил ложные срабатывания на разрешении нескольких
вызовов, условном запрете, исключении и отменённой цитате. Не переносить эти
regex flags в hard. Пользователь разрешил исправление парсера/механики; production
до приёмки остаётся прежним. S2 — новый исследовательский кандидат после S,
не выдаётся за заранее замороженный arm S/E2 или формальное доказательство NL.

Граница кода: единственный authoritative SYSTEM, preamble/instructions и policy
до catalog; только явно поддержанные безусловные whole-clause формулировки
MAX_ONE_CALL / NO_TEXT_WITH_CALL либо полный instructions either/or block.
История пользователя/инструментов не задаёт норму. Неизвестная связанная
формулировка, inherited scope/condition, разрешение/исключение/отмена нормы,
ошибка/неоднозначность parser дают UNKNOWN. Ничего не выводить из имени домена.
Сохранять буквальную цитату и spans, current-call/text факты и причины отказа.
Не считать нормой просто подстроку "one tool call at a time".

Только один current assistant message; tool results не являются текстом
пользователю. Пустота/служебный role header и закрытые think/analysis blocks
не считаются сообщением. Незакрытая/неясная разметка даёт UNKNOWN.
Любой transfer_to_human_agents в target пока исключает оба structural-hard
кандидата: разрешить семантику transfer first-call/then-message отдельно,
не превращать её в новый FP. Наличие двух read calls без применимого запрета
не является нарушением; исключение read-only сохраняется, не игнорируется.

Проверки до выводов: production-compatible отрицательные/метаморфные случаи
S плюс transfer, whitespace, headers, thoughts, quoted/obsolete rules, условие
на предшествующей строке/heading, user-owned tool call, tool-result-only text,
две assistant messages. Положительные — одиночный явный запрет и compound
retail/airline формулировки. Не ослаблять UNKNOWN ради полноты.

На seen397/real191/valid46 и dev520 подсчитать все срабатывания и каждый gold0
случай, без смены меток. Оценить оба заранее выбранных режима: hard consuming
quota .40 и OR после прежнего решения, отдельно для35B и фиксированной M3 где
доступны скоры. Пересчёт квоты обязателен; показать вытесненные TP/FP и paired
group bootstrap1000/CI95. Правило не подгонять под gold0 различия: правка scope
только по источнику/контрпримеру, новая версия и сохранение неудачного варианта.
Ноль FP на просмотренных наборах — необходимая локальная проверка, но не
доказательство закрытого переноса/полной семантической безопасности. Production
не менять до совместной приёмки и target-runtime проверки; ZIP не собирать сейчас.
