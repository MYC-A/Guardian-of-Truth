## Что исправлено (src/guardian_truth/v6fix, исходный v6 не тронут)
- Каждая находка = **факт** (проверен кодом на текущем входе, `recheck`) + **норма** с основанием `CONTRACT_TEXT` /
  `MODEL_EXTRACTION` / `NONE`. Решает только `MECHANICAL`; `HYPOTHESIS` выводится, но не решает. Границы — `GUARANTEES.md`.
- S: «не объявленный инструмент» только при полном каталоге И повторном разборе текущих деклараций; повтор после ошибки —
  всегда гипотеза (нормы нет), транзиентные ошибки / реплика пользователя / неоднозначная пара вызов-результат — не факт.
- P: тип поля из схемы (id-ссылка / значение / enum / «новый id»), точное совпадение с учётом регистра, примеры «such as»
  не источник, неполный вход ⇒ отсутствие недоказуемо; MECHANICAL только при цитируемом контракте происхождения,
  **покрывающем поле** (называет его или говорит об id/значениях вообще); `NOT_FROM_USER` для полей, которые контракт
  требует «от пользователя» (CaMeL).
- F: извлечение правил по тексту строк (без id источника), привязка цитаты к текущему входу, проверка числа/запретительности,
  условий/исключений/скоупа/субъекта, согласие двух прогонов.
- CLI: `--repair v6fix`, `--layer-budget-bytes` (по умолчанию = контекст R_fix), `--full` теперь выдаёт результат v6/v6fix
  (result, layers: findings/rules/records/coverage/budget/extraction, recheck, r_fix); у каждой находки `fact_basis` и `norm_basis`.
