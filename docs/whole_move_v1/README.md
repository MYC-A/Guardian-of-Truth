# Проверка всех действий текущего хода — 2026-10-05

Реализован общий механизм обхода current targets и проверок исходных объявлений.
Имена инструментов, полей, сущностей и ID строк не зашиты в runtime. Новый
reviewer обязан явно оценить каждый текущий target; одних слов «проверь весь ход»
теперь недостаточно. Интерпретация естественного языка остаётся гипотезой LLM.

Ветка: `research/whole-move-v1-20261005`, база `49d887bd`.
Код и тесты до API: `1b56371c`; протокол и запросы до API: `001fedc9`.
Production, исходный gold и все исторические frozen phases сохранены.

## Что реализовано

- Полный инвентарь целей: текст и все вызовы, включая второй и последующие.
  Отсутствие оценки, дубль или подмена историческим/user-действием — явный отказ.
- Governing policy, применимость, условия, предпосылки и исключения отделены.
  Буквальные цитаты и native actor проверяются кодом. AND-условия запрета не
  сводятся к одному выполненному условию. PERMIT не превращается в обвинение.
- Итог собирает код. Известная применимая exemption освобождает от несущественных
  неизвестных предпосылок. Неопределённая/противоречивая семантика даёт UNKNOWN.
  Все смысловые утверждения сохраняют `MODEL_HYPOTHESIS`.
- Независимый mechanical слой проверяет required/type/enum из исходных
  объявлений во всех текущих assistant calls. Неподдержанная грамматика и
  неоднозначность дают GAP. Форматная ошибка JSON сама по себе не объявляется
  нарушением задачи. Tool-universe closure по умолчанию выключена.
- Generic positive constraints не подтверждают корректность бизнес-действия.
  NO_ERROR нельзя получить только потому, что параметры соответствуют schema.
