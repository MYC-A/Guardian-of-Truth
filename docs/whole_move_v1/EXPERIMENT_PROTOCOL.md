# Whole-move reviewer: протокол до нового inference

Исходная проблема: I4 просит проверить весь текущий ход, но возвращает единственный
`regulated_action`. Поэтому дальнейшие вызовы могут остаться без явной оценки.
Цель — проверить общий контракт обхода всех текущих действий и отдельный слой
механических ограничений из исходных объявлений. Production не меняется.

База: `49d887bd552d041078c74b577bcd7a125bbd1dc9`.
Ветка: `research/whole-move-v1-20261005`.

## Изменения

- Ответ обязан содержать ровно одну оценку для каждого исходного current target,
  включая текст и поздние вызовы. Пропуск, дубль и подмена историческим действием
  отклоняются. Постоянного ограничения на число целей нет; ограничение output
  сообщается явно, оборванные ответы отклоняются.
- Применимость, условия, обязательные предпосылки и исключения описываются
  отдельно. Governing policy и свидетельства содержат буквальные цитаты с native
  actor. Код проверяет адреса, цитаты, инвентарь и согласованность, затем агрегирует.
  Это **MODEL_HYPOTHESIS**, а не доказательство правильной интерпретации.
- Все условия одного запрета образуют конъюнкцию; альтернативы должны явно
  описываться внутри одного условия. Разрешение само по себе не обвиняет.
  Известное применимое исключение освобождает от несущественных неизвестных
  предпосылок; противоречащие друг другу утверждения дают UNKNOWN.
- Механический слой проверяет все текущие assistant calls по явным required,
  type и enum в объявлениях. Имена инструментов/полей берутся из входа.
  Неизвестная грамматика, неоднозначные объявления и неявные ограничения дают GAP.
  Отсутствие инструмента не обвиняет без отдельной явной предпосылки закрытого
  tool universe; в этом эксперименте она выключена.
- Прохождение schema-проверки не означает NO_ERROR для бизнес-политики.
  Механическая положительная находка может отдельно дать ERROR.

## Сравнение

Шесть ранее разобранных исходных valid rows берутся целиком из предыдущего
selection sidecar. Это известная диагностическая выборка, не новый hidden test.
Дополнительно независимый участник команды создал 12 коротких новых примеров:
шесть пар про дополнительные вызовы, persistence проверки для той же сущности,
исключения, завершённость процесса, identity и chronology. Существенные
предпосылки полноты/авторитетности указаны в самих исходных политиках.
Это author-controlled contrast suite, не внешний независимый holdout.

Каждый вход проходит исходный parser, FULL pack и resolve. Старый I4 и новый
reviewer получают **одинаковый полный пакет**. Исторические ответы на усечённых
пакетах не считаются baseline этого сравнения. Оба запроса используют
`ministral-14b-2512`, temperature 0 и output cap 3600. Новый JSON-контракт имеет
другой overhead; стоимость измеряется, равенство количества токенов не заявляется.

Два inference arms: BASELINE и WHOLE_MOVE. После этого отдельно считаются
WHOLE_MOVE_PLUS_MECHANICAL и MECHANICAL_ONLY. Промежуточные UNKNOWN/technical
сохраняются даже при перекрытии механическим ERROR; бинарное преобразование — 0.
Метки/ожидаемые причины находятся только в evaluation sidecar, не в requests.

Предел: **36 single-attempt HTTP, 280000 provider/reserved tokens**, timeout120s.
Ошибка провайдера/неизвестный usage останавливает новые запросы к нему; смены
модели и повторов нет. Несовпадение actual model останавливает оставшиеся запросы.
Контекст проверяется по консервативному UTF8 bound с output reserve; входы
не обрезаются. Незавершённые ответы отклоняются. Provider raw, запросы и ledger
сохраняются. Число плановых строк и число выполненных запросов различаются.

До API фиксируются код, inputs, jobs, механические результаты, gold sidecar,
версии пакетов, исходный valid hash и protocol hash. После ответа обязательно
сравниваются не только метки, но и объяснения с исходными правилами. Улучшение
одного JSON-контракта не считается улучшением причин нарушения.

## Дешёвая предварительная проверка

На всех исходных 46 строках механический слой проверяет объявления без LLM.
Старые 12 наборов предсказаний используются отдельно для offline OR replay.
Это диагностический расчёт по сохранённым решениям, не новый LLM-прогон на46.
Оригинальные gold, production и все прежние frozen outputs остаются неизменны.

Воспроизведение: `PYTHONPATH=.:src`, `PYTHONHASHSEED=0`, далее
`python -m experiments.whole_move_v1.offline` и
`python -m experiments.whole_move_v1.runner prepare|run --live|report`.
`run` без `--live` допускает только сохранённый cache.
