## Method semantics and evidence

Source method groups contain full tool/provider/version/schema identities,
resource namespace, argument identity path, exact effect predicate/value and
authority references. Version alternatives remain explicit compatible members.
Different method families remain separate meanings, not a union or a vote.
Only application-supplied T1/resource declarations populate this catalogue.
T2/LLM proposals cannot enter T1 or establish effects, facts or necessity.

The new LLM pass returns candidate catalogue IDs and unresolved terms only.
It sees the original deterministic span/C2 fields and source method definitions,
not reference outcomes or actual occurrence truth. Its array has no confidence
ranking/top-k limit. A finite catalogue does not prove natural-language closure.

Entity refs must occur literally in the span. All source-owned ID and historical
alias matches survive, including renamed/retired names and duplicate aliases.
ID lookup and alias lookup use caches/indexes, not full trajectory comparisons.
One unresolved explicit ref cannot disappear because another ref was resolved.
Only source String-ID method codecs are currently supported: incompatible or
undeclared codecs stay UNKNOWN, not a false absence/completion count.

Each retained meaning/entity generates a v4 typed method-history query through
the actual T1 evaluator and independent temporal receipt checker. Actor,
result/call identity, scope, version/schema and exact effect value must match.
Undo cannot erase completion; later GET cannot repair timeout completion.
Absence of completion requires the correct scoped history premises.

Qualified dates/order/repetition/counts, causal claims and unknown/true C2 causal
flags cannot be silently lowered to generic method-history occurrence. This is
deliberately not a native count/state/causal proof implementation. All such cases
remain diagnosable; full Core must retain their unknown obligations.

## Independent native receipt

A second checker binds the full source envelope, source declarations/T1,
native graph, retained source-method meanings, all bindings and primitive
receipts. It independently enumerates original source records and validates
exact generated query actor/polarity/time/method/entity, dropped alternatives,
completeness and consensus. It does not invoke binder, backend or query generator.
Shared source lexical inventories/T1/temporal checks are explicit primitives.

The receipt is **conditional on the supplied C2 fields and retained meanings**;
quote membership/catalogue membership does not prove NL entailment. Coverage is
EMPIRICALLY_COVERED or OPEN_SEMANTICS, never PROVABLY_CLOSED from LLM silence.
These are not Goal permission proofs, mandatory process rules or whole-Core
ERROR/NO_ERROR certificates. Main solver/certificate composition remains required.

19 controlled-backend runtime/tampering checks use separate IDs and sentences,
not the scored binding extension or blind labels. They establish source/proof
integration and invariant handling, NOT actual model claim accuracy or downstream
gain. Separate committed candidate/model/input freeze precedes any model benchmark.
The only API process remains the frozen 104-case Policy comparison.
