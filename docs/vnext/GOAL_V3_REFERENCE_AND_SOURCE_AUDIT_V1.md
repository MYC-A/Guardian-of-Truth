## Source counterexample before repair

Source: `outputs/vnext/source_delimiter_v3_counterexample_v1.json`. Two public
synthetic examples exercise the current normalizer. An escaped marker/newline
inside valid JSON creates no extra SYSTEM event. An unterminated JSON string
followed by an unescaped SYSTEM marker does create a SYSTEM event in the legacy
source parser. No real user history, API key or private blind example was used.
No global claim about all delimiter forms follows from these two examples.

This source-boundary problem is NOT fixed. Do not describe the current source
normalizer as authenticating arbitrary plain transcripts. The frozen Goal/T2/
Policy versions stay untouched. A future version must prefer adapter-owned,
explicit role boundaries and bind source text/offsets to those records; malformed
or ambiguous framing must remain incomplete rather than gaining source authority.
Raw transcript heuristics cannot cryptographically authenticate who authored text.
Independent certificates must reconstruct the same authenticated source envelope,
not trust a solver-created event or a target-authored result.
