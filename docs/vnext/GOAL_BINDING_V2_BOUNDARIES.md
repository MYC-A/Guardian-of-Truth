# Goal/Plan v2 operational binding development

`goal_invocation_v2.analyze_goal_invocation` now connects the nine narrow native
source-reading tasks, source-owned interface/path binding tasks, exhaustive
binding choices, Goal-layer proof solver and independent certificate checker.
The backend must be supplied explicitly; this entry point neither reads keys
nor creates a client. It is not yet the single policy/claim/effect Core.

A semantic reading may permit a SET of tools. Those tools are one meaning,
not mutually exclusive worlds. Distinct meanings remain separate alternatives;
all per-source alternatives are multiplied without top-k pruning. Overflow
stops as incomplete. Failed or unknown tasks retain unbound placeholders.
Semantic interface membership establishes attempted invocation compatibility,
never completion, an observed effect or authoritative natural-language closure.

Argument paths are deterministic IDs from flat or wrapped function schemas and actual
target argument keys. Literal scope checks copy every source-allowed JSON
value without subsetting. Semantic mappings are candidates, not trusted facts.
Alias/entity-reference resolution and range/cardinality semantics
are not implemented in this development path. Such
inputs must not be advertised as supported literal-scope semantics.

No ordered plan means expected step is N/A, not zero or completed. The source
GOAL then constrains current workflow conformance, including plausible
preparatory actions rather than requiring immediate final-goal completion.
Finite tool catalogs do not close workflow meaning.

Plan progress requires a supplied authoritative activation/completeness premise.
No activation is inferred from empty history, an LLM estimate or benchmark gold.
Intervening activity still needs trusted later-progress grounding. Duplicate tool
metadata names are rejected rather than silently transferring a T1 version.

Remaining: extra IF/ONLY_IF/UNLESS proposition bindings, completed/state targets,
later progress, authoritative safety closure, source adapters and single Core
world/certificate composition. Scope beyond literal values remains incomplete.
NO_ERROR is intentionally not certifiable under empirical Goal semantics.

Twenty-six new controlled tests cover operational binding generation and the
entry point. These prove implementation behavior only. No v2 model stage or
blind evaluation has run; semantic/downstream gain remains NOT_ESTABLISHED.
The separate native v2 runner now supports a committed freeze and field-specific
transport/schema exclusions before starting that model evaluation. It keeps the
original benchmark's missing activation premise explicit rather than changing
the inputs to obtain a definitive verdict.
