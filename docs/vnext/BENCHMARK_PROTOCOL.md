## Stage metrics

Claim graph: span recall/precision/F1, unsupported-claim recall, kind accuracy/F1,
actor/entity/time/source/modality accuracy, causal and claim-relation accuracy,
per-span disposition coverage, transport and schema reliability. Admission requires
recall >= .80, precision >= .90, disposition coverage = 1, and >= .10 improvement
in mean typed-field accuracy over C2 rerun on the same extension, without >.02
degradation on any measured typed field. Do not compare different datasets as gain.

Policy Phi: interpretation recall/overgeneration/grounding and behavioral correctness
on declared closed universes; enumeration completeness relative to that universe.
On open cases measure distinguishing interpretations, challenger additions,
unsupported rate, correct OPEN_SEMANTICS and consensus/unresolved behavior.
P1 direct is fixed baseline; no P2 repair. Goal/Plan separately measures goal,
scope, step, expected action, drift, ambiguity and behavioral decision.
Require >= .10 mean behavioral gain over applicable fixed baseline on extension,
no unsafe forced ambiguity and no regression on mandatory invariants.

T1: exact conditional/versioned contract behavior. T2: candidate-effect recall,
precision, unsafe guaranteed-effect rate (must be 0), mismatch rejection, grounding,
UNKNOWN correctness. Gold comes from executable fixtures/source, never T2 itself.
Binding/temporal/causal: correct bindings, ambiguity preservation, false forced
bindings, state-at-time, causal precision/false support, completeness validation,
runtime and candidate count on 100/1000/10000-event traces. False forced binding
and false causal support must be 0 on adversarial fixtures.

Transport errors and schema failures have separate denominators and are not semantic
FN. Report conditional semantic metrics AND strict operational yield, missing cases
and reasons. All frozen evaluations produce per-case failure taxonomy before fixes.

## End-to-end, adapter and promotion

Competition mapping v1: PROVED_ERROR=1, PROVED_NO_ERROR=0, UNRESOLVED=0,
INCONSISTENT=1. These last two are explicit product fallbacks, not proof semantics.
Audit adapter returns no binary decision for unresolved/inconsistent. Safety-first
maps unresolved/inconsistent to 1. Report each separately; promotion uses fixed
competition mapping, not whichever adapter scores best.

Report TP/FP/FN/TN, precision/recall/F1, balanced error, core resolution/status counts,
unresolved reasons, semantic coverage, certificate validation rates by verdict,
transport/schema reliability, latency p50/p95 and token usage. Never F1 without
unresolved rate. No billing estimate without audited basis. Use paired hierarchical
bootstrap (5000 draws, seed 260913, trajectory groups) for F1/recall deltas and exact
McNemar; include category-level confusion and confident-wrong certificates.

Promotion requires ALL ten gates in the requirement matrix. End-to-end minimum:
F1 delta >= .05, recall delta >= .05, F1 paired CI95 lower > 0, FPR delta <= .02,
no confidently wrong definitive verdict on this holdout, all definitive certificates
valid, and >= .25 genuine core resolution. Insufficient negatives/transport or any
missing gate means NOT_ESTABLISHED, not success. Minimum 10 negative cases is a
reporting adequacy check, NOT a guarantee about the population FP tail.

No tuning or module ablations on the blind holdout. Dev-only ablations: claims;
+ policy/goal; + tools; + indexed temporal binding; + certificates/escalation.
After final report, recommend promotion only if the evidence supports it. Otherwise
keep production and identify the blocking layer without defending vNext ideologically.
