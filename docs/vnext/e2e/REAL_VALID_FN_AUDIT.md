## 17. Soundness observations recorded, NOT fixed (directive §27)

1. Claim disposition degradation: `VERIFIABLE_TYPED + any empty/UNKNOWN field
   (object, entity_refs) -> UNKNOWN_SEMANTICS` systematically destroys
   object-less ACTION_COMPLETED claims (telecom t27 root cause). This is a
   soundness-relevant REPRESENTATION gap, not a soundness bug: it abstains
   rather than fabricating. Recorded, not fixed.
2. World-conjunction masking: an axis-independent certified FALSE witness
   (catalog membership) is absorbed by unrelated UNKNOWN markers (goal SCHEMA
   failure, unresolved terms) in `negate(conjunction(safety))`. The mask is
   CONSERVATIVE (never fabricates ERROR), so it is not a soundness bug; it is
   recall loss. Recorded, not fixed.
3. H0 single-flat-structure parsing of multi-section competition policies
   produces garbage readings (forbid-everything lists, wrong requirements).
   Wrong-but-untrusted readings abstain safely; no false certification
   observed. Recorded as the main policy-extraction gap.
4. Cross-tool binding: in banking_051 a FORBID rule for
   `call_discoverable_agent_tool` was operationally bound to an
   `unlock_discoverable_agent_tool` call (different tool) producing an
   accidental FALSE witness. It was masked by world disagreement (sound
   outcome); certifying it would have been a wrong-reason TP. Recorded.
